# FlyAsia Asia Miles Tools Research

> 研究对象：FlyAsia 三个 Asia Miles 工具（兑换地图 / 混舱兑换计算器 / oneworld 规划器）
> 研究方法：浏览器实际操作（每个工具 5–20 组参数实测）+ 站内文章检索 + andrelyt/asia-miles-optimizer 仓库研读
> 证据标签：DOCUMENTED（网站文字说明）/ OBSERVED（工具实测）/ INFERRED（推断）/ UNKNOWN（未知）
> 日期：2026-10-15

---

## Executive Summary

1. **混舱计算器公式已完整逆向**（OBSERVED，18 组实测全部吻合）：
   `mixed_miles = floor( Σ_i [ d_i / D × rate(cabin_i, band(D)) ] / 100 ) × 100`，
   其中 D 为总距离，费率按**总距离**所在距离段查表（不是按每段距离），每段按自身舱位费率 × 距离占比摊分，最后向下取整到百位。顺序无关。该公式与仓库 V1.1 `standard_mixed` 实现同属一个公式家族（仓库：距离比例分配 + 向下取整至百）。
2. **"oneworld 分段兑换规划器"名不副实**（OBSERVED）：该 URL 上的工具实际是「Asia Miles 換環球票計算機」——只对手工输入的多航段行程做 oneworld 距离带查表 + 规则校验。**没有**分界点概念、**不**推荐城市、**不**自动合并多旅程、**不**对比单独/合并兑换、**不**排序候选。V2 的 D2（理论多旅行程结构）不能从该工具借鉴合并逻辑，只能借鉴它的规则校验清单和 13 档距离带表。
3. **兑换地图是纯静态查表工具**（OBSERVED）：输入里数 → 显示所有"最低票价 ≤ 输入里数"的香港（及 TPE/NRT/SIN/BKK）出发航点；`×N程 = floor(输入里数 / 票价)`；不验证真实航班、不查奖励座位、不含税费；数据更新时间有标注（2026-10-15 11:36 HKT，DOCUMENTED）。
4. **三个工具都不验证奖励座位、不验证可出票性**（DOCUMENTED：页面声明以官网/客服为准，实际出票需致电 +852-2747-3333）。任何"X→Y 省 Z"的数字都是理论值。
5. **对 V2 最值得借鉴**（详见 Recommended V2 Enhancements）：混舱 18 组测试向量（转成 V1.1 回归测试）、Category 2 规则核对、award-map 预算过滤 + ×N程展示、航司-航线已知执飞软校验、同城多机场识别、开口自动判定、行程 URL 编码分享。

## Tool 1 — Award Map（兑换地图）

URL: https://www.flyasia.co/miles/asia-miles/idea/

### 输入（OBSERVED）

| 字段 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| 里数 | spinbutton | 15000 | min=1000, max=999999, step=1000；非数字被 number 框拒绝 |
| 出发地 | combobox（自动补全） | HKG 香港 | 实测 TPE / NRT / SIN / BKK 均可用；输入过短时无建议 |
| 立即查看 | button | — | 触发查询；URL 仅带 `?origin=XXX`，不带里数参数 |
| 区域筛选 | 8 个按钮 | 全部 | 全部 / 東亞 / 東南亞 / 南亞 / 中東 / 歐洲 / 北美洲 / 大洋洲 |

OBSERVED：页面**没有**舱位选择器、**没有**单程/来回选择器。**没有**头等舱（全站只出现經濟 / 特選經濟 / 商務）。

### 输出（OBSERVED）

- 顶部摘要：`{可达航点数}` + `{最低里数} 里`（如 73 / 4,000 里）。
- Leaflet 地图：标记为该航点最低里数的千位缩写（4k/6k/9k…40k）。
- 航点卡片：默认 5 张，可展开全部。每张卡片：国家/城市标题、机场代码、兑换表（列=航空公司，行=經濟/特選經濟/商務）、5 家 Agoda 酒店推荐。
- 单元格为里数或 `—`（该航司无此舱位，如香港快运的 PE/J 恒为 —）。
- `×N程`：输入里数可换 N 趟单程，`N = floor(输入里数 / 该票价)`，仅 N≥2 显示（OBSERVED：4000 里查 4000 票价无 ×N；85000 查 4000 显示 ×21程；999999 查 4000 显示 ×249程）。
- 卡片按最低里数升序排列；同里数内顺序无明显规律（UNKNOWN，可能为数据集内置顺序）。

### 核心算法（INFERRED，基于 20+ 组观测）

1. **筛选规则**：某航点当且仅当其"所有（航司×舱位）票价中的最低值 ≤ 输入里数"时出现。
2. **票价 = 奖励图表距离带查表**（按航司区分），非实时查询。证据（OBSERVED）：HKG 出发 CX 各舱票价随距离呈标准阶梯（TPE~500mi→7,000；SIN~1600mi→9,000；TYO~1800mi→13,000；SYD~4570mi→20,000；LHR~5970mi→27,000；JFK~8070mi→38,000）。伙伴航司用另一套表（JL / QF / BA / AY / QR / MH / CA / 深圳航空 / 曼谷航空 / FJ 等，见测试用例）。
3. 不同出发地的同一航司票价不同（INFERRED：按出发地-目的地距离查表）。
4. 行程类型恒为单程（DOCUMENTED，FAQ）；来回 = 单程 ×2。

### 页面明示规则（DOCUMENTED，FAQ/说明文字意译）

- 整合国泰、香港快运（經濟飛/隨心飛）及主要 oneworld 伙伴的单程 Y/PE/J 兑换标准；可兑换航司按枢纽列出（含 oneworld 之外的国泰合作伙伴；实测卡片出现星盟航司中国国航、深圳航空、瑞航、汉莎、纽航及曼谷航空，证实含非 oneworld 伙伴）。
- FAQ 称"穷举所有由香港出发"的路线——**已过时**（OBSERVED：TPE/NRT/SIN/BKK 出发均可用，FAQ 文案疑似未更新）。
- 2020 年规则修改后单程转机停留 ≤24 小时；单程最多含 1 家合作伙伴（CX+伙伴A ✓、两段同伙伴 ✓、伙伴A+伙伴B ✗）；含伙伴用伙伴表计价、更贵。
- 免责声明：资料仅供参考，实际航班/舱位/里数以官网为准——即**不查实时座位、不含税费**。
- 数据更新时间：**「數據更新於 2026-10-15 11:36 HKT」**（页面底部明示，DOCUMENTED）。

## Tool 2 — Mixed Cabin Calculator（混舱兑换计算器）

URL: https://www.flyasia.co/miles/asia-miles/calculator/

### 输入（OBSERVED）

- 模式切换：单个 checkbox，默认「國泰航空（純國泰）」，勾选后为「涉及合作夥伴」（**整单**切换计价表）。
- 出发 / 转机点 / 目的地：IATA 三字码文本框（maxlength=4，带自动补全，如 HND 显示"东京羽田"）。
- 每段舱位下拉框（两段独立）：經濟艙 / 特選經濟艙 / 商務艙 / 頭等艙。
- 页面默认值：TPE→HKG（商務艙）+ HKG→HND（經濟艙），纯国泰模式。
- **工具固定只支持 2 段**（一段转机），无"添加航段"控件；单程票模型。

### 公式（VERIFIED_BY_TOOL；工具自身以四步骤明示 = DOCUMENTED_BY_SITE）

设 d1、d2 为两段大圆距离，D = d1+d2：

- 步骤1：D = d1 + d2
- 步骤2：由 D 落入距离段（751–2,750 段再分 類別1 / 類別2：行程涉及日本、印尼、印度、尼泊爾、孟加拉、斯里蘭卡 → 類別2，较贵，工具显示 ⚠️ 警告）
- 步骤3：每段摊分里数 = d_i ÷ D × rate(该段舱位, 该距离段)，显示时四舍五入到整数
- 步骤4：总里数 = 两段相加后**向下取整至百位**（floor 到 100）

即：

```
mixed_award_miles = floor( Σ_i [ d_i / D × rate(cabin_i, band(D)) ] / 100 ) × 100
```

### 假设检验（VERIFIED_BY_TOOL）

- (a) 每段按自身舱位独立计价再相加：**被证伪**。T1 若按此应为 7,000(Y,1–750)+33,000(J,751–2750)=40,000，实际 28,600；T6 应为 11,000+23,000=34,000，实际 23,000。
- (b) 按最高舱位整单计价：**被证伪**。T1 实际 28,600 ≠ J 全价 33,000；T4 实际 30,800 ≠ 33,000。
- (c) 距离比例 × 各段自身舱位费率（费率取自"总距离"所在距离段）：**被全部 18 组支持**。
- 顺序无关：T1 与 T2（航段顺序+舱位整体对调）结果完全相同（VERIFIED_BY_TOOL）。
- 距离段按**总距离**而非每段距离判定：被证实（T1 中 498mi 段用的是 751–2750 段费率而非 1–750 段费率）。

### 取整 / 最小值 / 边界（VERIFIED_BY_TOOL 为主）

- 每段摊分里数显示为四舍五入到整数（恰为 .5 时的进位方向 UNKNOWN，未观测到）。
- 最终总里数**向下取整到百位**（floor）：28,666→28,600 排除了"四舍五入到百位"的可能。
- 最终取整是对"精确值之和"还是"显示值之和"取整：UNKNOWN（本测试中两者无差异）。
- 无独立最低兑换门槛；最低价即图表最低值：纯国泰 7,000（Y，1–750）、伙伴 10,000（Y，1–750）。
- 距离段边界（工具显示值）：1–750 / 751–2,750（分 類別1/類別2）/ 2,751–5,000 / 5,001–7,500 / 7,501+（顶段无上限）。
- 工具内部用**未取整**的大圆距离计算、显示取整值：INFERRED（证据：用显示距离手算与工具显示的每段里数有 ±3–5 的系统性偏差，如 T0 的 7,151）。

### 错误与边界（VERIFIED_BY_TOOL）

- 无效 IATA（如 XXX）：结果区直接消失，**无明确错误提示**。
- 起点=终点（如 HKG→TPE→HKG）：结果区消失、无错误提示——工具不支持纯往返建模（使用说明亦写明"第一段的起点必须与第二段的终点不同"）。
- 转机点无国泰/oneworld 定期航班（如 MFM–HKG、SFO–JFK）：仅 💡 软警告，不阻止计算；涉及非国泰承运段时建议改用"合作夥伴"模式。
- 三段式混舱（Y+W+J）：**不支持**，仅固定两段（DOCUMENTED：该站称單程兌換僅能有 1 次轉機）。
- 往返"去程一舱、回程另一舱"：工具内无法直接建模，需拆成两个单程分别计算（INFERRED）。

### 与官方规则的差异（供审慎参考）

1. 该站声明兑换表为自行根据 Asia Miles 搜索结果手工整理（"國泰不再公佈兌換表格"），2026-05-01 生效；距离数值与官方或有误差（DOCUMENTED）——费率与官方实际可能存在出入。
2. 模式切换是对**整单**套用一张表，无法按每段实际承运航司分别计价；而按该站整理的官方规则，只要行程中有一段是伙伴承运，整单即按伙伴表计价（DOCUMENTED）——工具用模式开关近似此规则，属简化。
3. 混舱按距离比例摊分、向下取整到百位：与官方规则表述方向一致，但官方是否同样"向下取整到百位"为 UNKNOWN；工具未展示官方条款原文。
4. 工具只计算里数，**无燃油附加费/税费**。

## Tool 3 — oneworld Planner（oneworld 环球票计算器）

URL: https://www.flyasia.co/miles/asia-miles/oneworld-planner/

> **重要澄清（OBSERVED）**：该 URL 上的工具实际名称是「Asia Miles 換環球票計算機」，**并非**自动"分段兑换规划器"。工具中**不存在**"分界点"概念：它不推荐城市（上海/东京/台北）、不自动合并多个行程、不比较"单独兑换 vs 合并兑换"、不对候选项排序。它只做一件事：**对用户手工输入的多航段行程，按 oneworld 距离带换算表计算里程并校验规则**。以下"分段规划"相关问题凡涉及自动化的，答案都是"工具不支持"。

### 工作流程（OBSERVED）

1. 每航段三个输入：出发地机场、目的地机场（combobox，支持机场代码/中文城市名/机场名模糊搜索；输入"東京"出现 HND 東京羽田、NRT 東京成田两个选项）、停留类型下拉（停留/转机；最后一段显示"抵達"）、航空公司选择器。
2. 新增航段时出发地自动预填上一段目的地；目的地为空、航司为"请选择"。
3. 航司选择器智能行为：已知航线（如 HKG-JFK）下拉框预过滤只显示执飞航司（CX）+「显示所有 oneworld 成员…」；SYD-HND 显示 JL（已知执飞）在上，并有一条动态分隔线「──以下會令航空公司組合不符規則──」，把选了会导致航司数量不合规的选项列在分隔线下；未知航线（如 JFK-SYD，无直飞）直接列出全部 16 家。

## Observed Algorithms（三个工具的算法流程反推）

### 通用 pipeline（INFERRED，三工具共享同一家族）

```
输入（机场/里数/舱位/航段）
↓
机场 → 大圆距离（自有距离库，显示取整、内部用未取整值；INFERRED）
↓
奖励表查表（距离带 → 各舱里数；标准表 / 伙伴表 / oneworld 表三张）
↓
候选生成（award map：全量航点过滤；计算器：固定 2 段；planner：用户手工航段）
↓
规则过滤（planner 的计数器/航司数/回头路/开口判定；计算器的 Category 2；award map 无）
↓
里数计算（混舱：距离比例摊分 + floor 到百；oneworld：总距离查表；award map：单段查表）
↓
展示（排序/地图/检查清单；无统一排序优化目标）
```

### 各工具特有逻辑

- **Award map**：`SHOW(d) ⟺ min_{carrier,cabin} fare(d) ≤ input_miles`；`×N程 = floor(input / fare)`（N≥2 显示）；按最低里数升序。无剪枝、无推荐评分——"推荐"即全部符合条件的航点（INFERRED）。
- **混舱计算器**：公式见 Tool 2。剪枝：固定 2 段（单程 1 转机是硬约束，DOCUMENTED）；排序：无（单结果）。
- **oneworld planner**：无生成、无排序；核心是**校验器 + 查表器**。校验顺序（OBSERVED）：机场有效性 → 航司-航线匹配（软）→ 开口自动判定 → 计数器（停留/转机/开口）→ 航司数量 → 同国家/地区 → 不走回头路 → 总距离 ≤50,000（唯一隐藏价格的违规）。

### 数据来源（DOCUMENTED / UNKNOWN）

- 距离库来源：未公开说明（UNKNOWN）；工具声明"距离数值可能与官方有些微误差"。
- 航线库来源：未公开说明（UNKNOWN）；planner 用它做航司-航线匹配（已知执飞 vs 未知航线虚线警告）。
- 奖励表：**网站自行根据 Asia Miles 搜索结果手工整理**（DOCUMENTED："國泰不再公佈兌換表格"），混舱表标注 2026-05-01 生效；oneworld 表页面未标生效日期（UNKNOWN）。
- Award map 数据更新时间：2026-10-15 11:36 HKT（DOCUMENTED）；另两个工具页**无**更新时间标注（OBSERVED）。

## Potential FlyAsia Limitations（主动寻找的问题）

1. **兑换表是手工重建的**（DOCUMENTED："國泰不再公佈兌換表格"）：费率可能与官方实际有出入；距离"或有误差"（DOCUMENTED）。不要把工具输出当作官方报价。
2. **混舱整单模式开关是简化**（INFERRED）：无法按每段实际承运航司分别计价；官方"向下取整到百位"未获官方确认（UNKNOWN）。
3. **Award map 无头等舱、无错误提示、有 stale UI bug**（OBSERVED）：低里数输入后摘要/地图残留旧值；区域筛选不刷新计数；FAQ"仅香港出发"已过时。

5. **简单往返在工具口径下不合规**（OBSERVED）：HKG-HND JL 直飞往返因航司数量不足被判 ✕——这是工具对 oneworld 表适用条件的严格解读，实际出票时国泰客服可能有不同处理（UNKNOWN，需官方验证）。
6. **"3 套商务"玩法已死**（DOCUMENTED，B3 文章）：2023-10-10 规则更新（不走回头路）后旧分段技巧失效；任何基于旧文章的策略需重新验证。
