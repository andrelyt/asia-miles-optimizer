# Phase 2B-2 — opt-in reference chart estimates

This is a planning layer below an airline quote. The Phase 2B-1 audit remains
INCONCLUSIVE about official current/2027 tariff confirmation. That audit and its
original evidence are unchanged. No reference estimate resolves the official gate.

## Interfaces and explicit opt-in

- `price_candidate(candidate, request, rules, evidence=None,
  balances_by_account=None, reference_chart=None)` first runs the unchanged strict
  adapter/quote path. A valid complete quote takes precedence. With no profile,
  the old result shape and pricing behavior are retained.
- `reference_estimate(candidate, request, rules, profile)` validates the supplied
  profile and direct CX structure, then calls **V1.1 `cx_standard_base`** once per
  direction. It contains no second chart, mixed-cabin arithmetic or rounding.
- `optimize_portfolios(..., reference_chart=None)` replays the original evidence
  and profile. It does not trust a cached estimate or fake cached miles.
- `planner.py` accepts optional `reference_chart` as an inline object or local JSON
  path, with the same resource-resolution convention as its other inputs.

The explicit profile at `validation/2027_reference_chart_profile.json` records two
separately published reconstructions (Australian Frequent Flyer and FlyAsia),
publication notes, checked date, chart version, chart digest, exact rule-content
binding, and eight directional provisional bands. Numeric prices remain solely
in the versioned rules file. Both sources were rechecked on 2026-10-15 and their
six table rows agree with the supplied reference chart. Their claims remain
**SECONDARY_CORROBORATION**, never official or dated airline responses.

A profile requires `basis=SECONDARY_CORROBORATED_REFERENCE_CHART`,
`evidence_level=SECONDARY_CORROBORATED_REFERENCE`, nonempty chart version,
checked date no earlier than the bound snapshot's as_of, matching rules digest
and version, and two distinct publisher-domain source attestations with matching
chart digests and `independent_publication=true`. Source checks are syntax/content
binding checks, not source-authenticity or common-upstream verification. A human
must audit the publishers and their table agreement; two URLs alone are not proof.

## Scope

This phase supports exactly a direct CX outbound and direct CX return, represented
as separate per-direction Standard tickets, with supplied profile band coverage.
The shipped profile covers HKG↔CTS/SYD/AKL/ZRH only. It retains
DISTANCE_PROVISIONAL and the explicit CTS Type 2 source. Both directions need valid
bands and prices, and request cabin minimums still apply. J/J, W/W, J/W, W/J and
policy-allowed Y/Y are supported. Graph cabins are supplied possibilities, not
verified flight-specific cabin inventory.

Unknown/invalid bands, missing cabin price, insufficient corroboration, stale rule
binding or invalid candidate data yield no reference estimate and retain an
explicit diagnostic. Zero reference prices are rejected. Partners, connections,
separate-sector awards and new mixed formulas are outside this reference layer;
they retain the existing strict adapter behavior. A malformed actual quote is not
hidden by a reference fallback. A partial quote is retained as original evidence;
any fallback is a whole-candidate reference estimate, not a hybrid quote total.

## Pricing contract

With a valid profile but no complete quote:

```json
{
  "status": "RULE_ESTIMATED",
  "pricing_status": "RULE_ESTIMATED",
  "official_pricing_status": "RULE_VERSION_REVIEW_REQUIRED",
  "per_person_miles": null,
  "group_miles": null,
  "quote": null,
  "estimate": {
    "miles_per_person": 182000,
    "group_miles": 364000,
    "basis": "SECONDARY_CORROBORATED_REFERENCE_CHART",
    "distance_status": "DISTANCE_PROVISIONAL",
    "rule_applicability": "CURRENT_REFERENCE_NOT_VERIFIED_FOR_TRAVEL_DATES"
  },
  "award_seat_status": "NOT_CHECKED",
  "ticketability_status": "NOT_CHECKED",
  "complete_price_comparison_eligible": false

```

The example is reference arithmetic for two travelers, not an observed quote.
`estimate.tickets` contains directional/cabin/band requirements. `estimate` retains
source attestations, dates and digests. Candidate IDs stay unchanged; evaluation
and portfolio IDs change when reference evidence changes.

A valid quote still requires the existing candidate/rules/date-bound sourced
applicability review and AIRLINE_QUOTED per-ticket positive integer miles. The
adapter's evidence contract is unchanged. Quote values remain in original fields;
opt-in output also exposes a separate `quote` summary and `estimate=null`.
No manual APPLICABLE review, quote, tax or seat evidence is generated by this mode.

## Annual budgets

Reference totals enter annual allocation only through separate internal planning
tickets, reusing the existing indivisible passenger/ticket allocation engine.
Accounts are independent, never pooled or replenished per year. Payers need not be
travelers. Mathematical simulation does not attest payer/beneficiary eligibility.

A known-balance allocation may yield `status=ESTIMATED_BUDGET_FEASIBLE`; it remains
inside the **conditional** array. Missing/partial balances or a funding search limit
leave status CONDITIONAL and estimate budget_status UNKNOWN. An infeasible
indivisible allocation is rejected, even when summed balances cover summed miles.
Annual leave and per-year budgets still apply across all selected trips.

Reference portfolio values live in `estimate.total_miles`, `miles_by_traveler`,
account allocation/spend/remaining fields. Its budget scope is explicitly
MATHEMATICAL_SIMULATION_ELIGIBILITY_NOT_VERIFIED. Top-level quoted/confirmed total
and allocation fields stay null, and full-price comparison remains false. Mixed
quote/reference portfolios retain a separate combined planning estimate, but do
not enter homogeneous-reference Pareto pruning.

Safety correction found during review: the pre-existing same-ticket mixed-cabin
RULE_ESTIMATED kernel result could previously receive the numeric-budget label
CONFIRMED_BUDGET_FEASIBLE. It now receives at most ESTIMATED_BUDGET_FEASIBLE inside
conditional too. Its pricing algorithm/rounding/legacy numeric fields are unchanged.
No RULE_ESTIMATED portfolio is placed in the confirmed budget_feasible array.

## Views and planning Pareto

The strict complete-quote `dominates()` rule remains unchanged. A separate
**planning-only** Pareto comparison can prune estimates with equal reference
basis, destinations, holiday families, evidence dimensions, status, year layout
and account-key layout. Its vector includes estimated miles, trip count, duration,
longhaul and all-sector ordinal cabin experience (including CTS shorthaul), leave
by traveler/year, sectors/transfers, known destination full days, and simulated
per-account spend where available. Taxes are excluded from this explicitly limited
comparison; unknown cash is never zero or a full-price comparison.

Miles Saver orders evidence tiers QUOTED → RULE_ESTIMATED → UNKNOWN, then reference
miles. Balanced uses evidence tier, trip count descending, then miles, with no
weighted score. Pure reference views declare `ranking_basis=RULE_ESTIMATED_MILES`;
mixed quote/reference views declare EVIDENCE_TIER_THEN_MILES. Evidence-tier priority
is not proof that a quote is cheaper than an estimate. Comfort First and Leave
Efficient retain their existing ordering logic on the resulting front. This new
front may change their IDs; those views do not claim complete prices either.

`search_truncated` is preserved. Planning usefulness, cap stability, calendar,
route operation, award seats, tax completeness, funding eligibility and
bookability remain separate judgments. No 2027 tariff or global optimum is assured.
